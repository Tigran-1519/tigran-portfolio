# Портфолио Тиграна Шогояна

Статическое портфолио на русском языке: сайты, web-сервисы и сценарии ботов. Пять работающих браузерных демонстраций и материалы собственных проектов. Визуальный стиль: графит, почти белый фон, кобальтовый акцент и крупная типографика. Готов к размещению на GitHub Pages или любом статическом хостинге. Установка зависимостей и сборка не требуются.

## Локальный запуск

Откройте терминал в этой папке и выполните:

```text
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Если порт занят, замените `8000` другим свободным портом. Остановить сервер можно сочетанием Ctrl+C.

Основная страница также открывается непосредственно из `index.html`. Для проверки поведения буфера обмена предпочтителен локальный сервер. Копирование работает на HTTPS или localhost; если браузер не разрешает доступ к буферу, демо выделяет текст и предлагает скопировать его вручную.

## Что работает

- `index.html` — главная страница, пять крупных кейсов и реальные превью страниц в iframe. Превью загружаются лениво, скрыты от вспомогательных технологий и клавиатуры; у каждого проекта есть отдельная ссылка «Открыть». В сворачиваемой лаборатории есть редактор текста с живым предпросмотром. Редактор меняет заголовок, описание и подпись кнопки; кнопка показывает локальный статус, сброс возвращает исходный пример.
- `furniture.html` — адаптивный лендинг вымышленной мастерской «Тихий дом». Выбор изделия, отделки, размеров и помещения; условная иллюстрация; проверка числовых диапазонов; генерация структурированного текста заявки; копирование и сброс. Изменение параметров скрывает старую заявку до повторной генерации.
- `leadbot.html` — браузерный симулятор сценария бота. Три шага, разные цели для разных задач, итоговый бриф, копирование и перезапуск диалога.
- `desk.html` — BriefDesk, кабинет заявок: поиск, фильтрация, статусы, карточка заявки, импорт/экспорт JSON и локальное сохранение.
- `slotly.html` — Slotly, выбор услуги, даты и времени, локальная сводка записи и сброс. Без связи с реальным календарём.
- `eventbot.html` — EventBot, браузерный сценарий выбора формата и сессии, сводка участия, копирование и перезапуск. Без реального билета или регистрации.
- Семантическая разметка, подписанные поля, управление с клавиатуры, видимый фокус, сообщения о результате и поддержка `prefers-reduced-motion`.

## Ограничения

Браузерные страницы не отправляют заявки. Нет серверной части, аналитики, платежей или внешних библиотек. BriefDesk и Slotly сохраняют свои демонстрационные данные в localStorage этого браузера; они не передаются на сервер. Остальные сценарии работают только в текущей вкладке. В приватном режиме или при запрете хранилища локальное сохранение может быть недоступно. Редактор — локальная демонстрация, а не полноценная CMS; данные исчезают после перезагрузки. В мебельном демо не рассчитываются цена, конструкция или производственные допуски. Иллюстрации мебели условные, не масштабируются по введённым размерам.

MemoBook представлен предоставленным скриншотом, публичный адрес пока не подтверждён. Новый браузерный LeadBot — отдельный демонстрационный сценарий собственного проекта. LeadHunter описан как собственный инструмент обработки открытых данных и CSV; онлайн-версия и исходники этого проекта в данную папку не включены. Никакие кейсы не заявлены как работы для вымышленных заказчиков.

Состав этапа, стоимость, сроки и порядок оплаты обсуждаются отдельно. Работа с Codex честно указана в процессе на главной странице.

## Отдельный запуск ботов в Telegram

В репозитории также есть `telegram_bots.py` — отдельный Python runner для двух сценариев, LeadBot и EventBot. Он запускается локально по [TELEGRAM_RUN.md](TELEGRAM_RUN.md), требует Python 3.10+ и собственного `BOT_TOKEN` в окружении. Используется стандартная библиотека, установка пакетов не нужна. Есть inline-кнопки, возврат, отмена и временное состояние диалогов; для работы нужен запущенный процесс.

Это отличается от браузерных симуляторов: страницы GitHub Pages не подключены к Telegram, а Python runner работает с Telegram API после самостоятельной настройки. Реальные токены и запуск в Telegram не проверялись; боты не заявлены как уже работающие в Telegram. Токены, личные данные и рабочие `.env` не входят в публикацию.

## Ассеты и данные

- `MemoBook-example.png` — предоставленный пользователем скриншот собственного проекта MemoBook, копия из исходных материалов в `outputs/`.
- Иллюстрации мебели и мини-интерфейсы выполнены средствами CSS специально для этого портфолио. Заимствованные фотографии и сторонние графические материалы не использовались.
- Шрифты — системные Segoe UI Variable / Segoe UI / system-ui, без внешних загрузок.
- Название «Тихий дом», изделия, отделки и значения в демо вымышлены и предназначены для демонстрации интерфейса.
- Единственный контакт автора: https://t.me/tigr_SH.

## Публикация на GitHub Pages

Поместите содержимое этой папки в корень репозитория, затем выберите публикацию GitHub Pages из соответствующей ветки и корневой папки. Все ссылки на страницы и ассеты относительные: сайт подходит как для домена пользователя, так и для адреса проекта с префиксом репозитория. Файл `.nojekyll` отключает обработку Jekyll.
