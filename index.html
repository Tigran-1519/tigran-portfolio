До начала работы

Что получаете.
Как проверяете.

Для каждой задачи фиксируем состав и результат. Примеры того, что можно согласовать:

Лендинг услуги+

Результат: адаптивная страница с согласованными блоками, материалами и действием посетителя.

Приёмка: контент соответствует исходным данным, кнопки ведут по нужным адресам, на телефоне нет наложений. Если включена форма — проверяем получение тестовой заявки.

Посмотреть пример страницы ↗
Бот для сбора заявки+

Результат: согласованный диалог, который уточняет данные и собирает итог заявки.

Приёмка: проверяем все ветки, возврат, повторный запуск и итоговый текст. Подключение к Telegram, место получения заявки и размещение согласуем отдельно.

В портфолио — браузерные сценарии и код для Telegram. Работа с реальным Telegram API пока не проверена.

Пройти пример диалога ↗
Интерфейс работы с заявками+

Результат: рабочий интерфейс со списком, карточкой заявки, поиском и согласованными статусами.

Приёмка: добавление, изменение, поиск и перенос данных проходят по согласованным сценариям. Общее хранилище и интеграции оцениваем по требованиям.

BriefDesk показывает интерфейс и хранит данные только в браузере.
