# Проверка безопасности — 7 октября 2026

## Область проверки

Восемь статических страниц портфолио и демо, браузерные скрипты, JSON-импорт BriefDesk, локальное хранилище, предпросмотры iframe и исходный Python-обработчик LeadBot/EventBot. Сервер приложений, платежи, учётные записи пользователей и база данных в этом репозитории отсутствуют. Python-боты не запускаются на GitHub Pages.

## Исправлено

- Данные Telegram-кнопки с Unicode-цифрой могли вызвать необработанный ValueError и остановить процесс. Теперь принимается только ограниченный ASCII-формат и точный список вариантов; проверяется структура входящего обновления.
- Просроченная сессия могла восстановиться после ошибки доставки. Очистка выполняется до сохранения состояния для повтора и в цикле опроса, даже без новых сообщений. Диалоги удаляются примерно через 30 минут неактивности (с учётом ожидания сети и повторов).
- Команда /cancel теперь удаляет ответы даже при ошибке отправки подтверждения.
- Добавлены ограничение частоты обработки (12 обновлений на чат за 10 секунд, 20 глобально за секунду) и ограниченное хранилище счётчиков; превышение игнорируется без ответного спама. Это защита процесса демо, не распределённая защита от DDoS.
- На всех HTML-страницах включена Content Security Policy: запрещены eval, произвольные встроенные скрипты и обработчики, сетевые fetch/XHR/WebSocket, отправка HTML-форм, плагины и подмена base URL. Оригинальный встроенный скрипт MemoBook разрешён только по SHA-256. Локальные сценарии форм работают через JavaScript без отправки.
- Шесть iframe изолированы sandbox без allow-same-origin, top-navigation и всплывающих окон. Встроенные демо не получают доступ к родительскому документу и его локальному хранилищу. Для полноценной работы и сохранения данных открывайте отдельное демо.
- Добавлена политика no-referrer. Разбор сохранённых данных ограничен размером до JSON.parse: BriefDesk — 1 МиБ символов, Slotly — 4096 символов. Импорт BriefDesk уже имел лимит файла 1 МиБ и 200 записей.

## Проверки

- 16 тестов ботов: основные сценарии, изоляция чатов, устаревшие кнопки, неожиданный ввод, частота сообщений, истечение срока, отмена при сбое API и безопасные сообщения ошибок.
- Три статические проверки защищают CSP, хеш MemoBook и атрибуты iframe от регрессий.
- В браузере подтверждены блокировки inline-script, inline-handler, eval и сетевой отправки; доступ родительского окна к изолированному iframe запрещён.
- HTML-подобный ввод в редакторе, LeadBot, EventBot и JSON-импорте BriefDesk остаётся текстом. Неверный статус __proto__ отклоняется, существующие записи сохраняются.
- Проверены рабочие сценарии конфигуратора мебели, Slotly, обоих ботов, редактора, галереи и списка MemoBook.
- Поиск в текущих публикуемых файлах не выявил токенов Telegram/GitHub/AWS или приватных ключей по проверенным шаблонам. Это не полный анализ всей истории Git и настроек аккаунта.
- Сторонних устанавливаемых зависимостей и lockfile нет: браузер использует собственные JS/CSS, Python — стандартную библиотеку; пакетный audit неприменим.

## Ограничения

Это проверка кода и поведения демо, а не гарантия отсутствия всех уязвимостей. Проверка настоящего Telegram API не выполнялась: токены не запрашивались и бот не разворачивался. Защиту аккаунта GitHub, права токенов, восстановление аккаунта и весь Git-архив отдельно не проверяли.

Политика CSP задана в HTML. frame-ancestors (защита от встраивания внешними сайтами), HSTS, Permissions-Policy и X-Content-Type-Options требуют HTTP-заголовков; этот релиз их не устанавливает. Если появятся авторизация, платежи или реальные клиентские данные, нужны отдельный сервер/хостинг с контролем заголовков и отдельная проверка. Sandbox предпросмотра не изолирует демо, открытое напрямую на общем домене GitHub Pages.

style-src допускает встроенные стили для существующего оформления. Данные BriefDesk/Slotly в отдельных страницах хранятся без шифрования в браузере и доступны другим страницам того же origin. Используйте учебные, а не конфиденциальные данные. CSP не мешает обычным переходам по ссылкам и не заменяет контроль доступа.

Документация: [MDN: CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP), [MDN: iframe sandbox](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe), [MDN: frame-ancestors](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors).

Проверки запускаются командами `python test_telegram_bots.py` и `python test_security.py` из каталога проекта.
